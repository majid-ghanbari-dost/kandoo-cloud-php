# آزمون بار واقعی محلی P-24

`python tools/dev/load-mariadb.py --php C:\xampp\php\php.exe --concurrency 50 --requests 100` را با `KANDOO_CONFIG` برابر فایل config دمو اجرا کنید؛ Python 3 لازم است. CI همین سناریو را روی MariaDB 10.6 اجرا می‌کند. فقط دیتابیس loopback با نام دموی ساخته‌شده یا محیط تست `TEST_` پذیرفته می‌شود؛ هیچ مقصد شبکهٔ خارجی پذیرفته نیست. سرویس موقت فقط روی `127.0.0.1` گوش می‌دهد. کار از یک توکن تصادفی ساختگی برای lookup فاکتور ناموجود استفاده می‌کند؛ 404 موفقیت مورد انتظار است و هر نتیجهٔ دیگر/خطای اتصال خطاست. هیچ دادهٔ فاکتور خوانده یا چاپ نمی‌شود؛ هیچ ردیف نرخ یا فاکتور نوشته نمی‌شود.

برای اندازه‌گیری مسیر DB، محدودکنندهٔ عمومی فقط در فایل config موقت و پردازش آزمایش خاموش است؛ پیکربندی اصلی تغییر نمی‌کند. فایل موقت که حاوی تنظیم DB است در دایرکتوری موقت خصوصی قرار گرفته و در پایان حذف می‌شود. PHP built-in server با یک worker و ۵۰ مشتری هم‌زمان اجرا می‌شود (نه سرور production). p95 با روش nearest-rank روی زمان شروع درخواست تا دریافت پاسخ و نرخ خطا نسبت به کل درخواست‌ها محاسبه می‌شود. این عدد benchmark محلی همان محیط است، نه ادعای ظرفیت یا SLA تولید. بارگیری/تأیید کاربر و Windows در این تست اثبات نمی‌شود.
