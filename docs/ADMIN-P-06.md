# مدیریت P-06 — فاکتور دیجیتال کندو

مدیریت به‌طور پیش‌فرض خاموش است و مسیر صفحه در این حالت مانند مسیر ناموجود پاسخ می‌دهد. یک هش `password_hash` برای گذرواژهٔ مستقل مدیریت در پیکربندی خارج از مخزن قرار دهید؛ مقدار null مدیریت را غیرفعال می‌کند. فرمان CLI `php bin/admin.php enable` یا `disable` گذرواژه را عیناً از stdin می‌خواند (از جمله newline احتمالی)، و تغییر وضعیت و رویداد فعال/غیرفعال را اتمی ثبت می‌کند. از فایل محافظت‌شده و خارج از مخزن یا ورودی امن استفاده شود؛ رمز در آرگومان یا خروجی نیست. در وضعیت فعال، صفحهٔ `/admin` برای هر درخواست HTTP Basic با نام کاربری `admin` و همان رمز مستقل می‌خواهد. پیش از فعال‌سازی، HTTPS انتهابه‌انتها، محدودیت دسترسی در وب‌سرور و ارسال هدر Authorization به PHP باید در میزبان تنظیم و بررسی شود؛ Basic بدون TLS امن نیست. این صفحه هنوز امکانات عملیاتی دیگری ارائه نمی‌کند.
