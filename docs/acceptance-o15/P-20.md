- **تعداد واقعی تست‌ها و assertionهای سبز: NOT-VERIFIED.** artifactهای JUnit/output در GitHub برای هر run موجود فهرست شدند اما دانلود آن‌ها با EOF شکست خورد؛ log run نیز در این محیط EOF داد. از تعداد متدها عدد اجرای واقعی بازسازی نشده است. فایل‌ها از رابط همان run قابل بررسی‌اند.
- **تعداد skip PHPUnit: صفر، به استناد کنترل JUnit ضد-skip در workflow تگ و موفقیت step PHPUnit**؛ متن خروجی خام خودِ شمارش مستقل قابل بازیابی نبود. هیچ skip PHPUnit با دلیل ثبت نشده است.
- مرحلهٔ Actions به نام `Annotate PHPUnit failures` به شرط `failure()` وابسته است و در اجرای موفق skipped می‌شود؛ این skipِ workflow است، نه PHPUnit.
