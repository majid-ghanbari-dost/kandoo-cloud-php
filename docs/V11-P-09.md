# محدودهٔ v1.1 پیشنهادی در ابر — فاکتور دیجیتال کندو

این کار فقط شکل پیشنهادی و ثبت‌شدهٔ بخش ۱۱ قرارداد منجمد و دو شمای موجود `docs/schemas/v1-1/` را پوشش می‌دهد؛ U14 همچنان تأییدنشده است و این سند ادعایی دربارهٔ کامل‌بودن یا هنجاری‌بودن مشخصات مستقل Canonical Invoice v1.1 ندارد. مقادیر اختیاری همان‌طور که ثبت شده‌اند نگهداری می‌شوند و هیچ محاسبه‌ای از مانده یا پرداخت انجام نمی‌شود. مانده حتی بدون آرایهٔ پرداخت نمایش داده می‌شود؛ هر شیء پرداخت باید دقیقاً دو فیلد `type` و `amount` داشته باشد و دادهٔ نامعتبر تراکنش را بازمی‌گرداند. برای نسخهٔ قبلی رفتار و گلدن‌ها حفظ شده‌اند.
