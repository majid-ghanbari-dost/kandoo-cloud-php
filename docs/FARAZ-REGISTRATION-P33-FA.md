# بسته ثبت الگوهای پیامک — پیش‌نویس P-33

این سند متن پیشنهادی ثبت الگو است، نه تأیید ارائه‌دهنده و نه مجوز فعال‌سازی. SMS واقعی خاموش بماند تا مالک دامنه، شناسه خط، API key و شناسهٔ الگوها را خارج از مخزن تنظیم کند. یک base URL HTTPS نهایی باید قبلاً توسط مالک تأیید شود؛ جای‌نگهدار زیر هیچ دامنهٔ عملیاتی نیست.

## الگوی اعلان ثابت — بدون متغیر

```text
فاکتور دیجیتال کندو برای شما ثبت شد. برای مشاهده فاکتورها به نشانی https://FINAL-DOMAIN-PLACEHOLDER/account/login مراجعه کنید.
```

آدرس باید پیش از ثبت الگو با URL نهایی و ثابت جایگزین شود؛ هیچ شناسهٔ فاکتور، شماره تلفن یا لینک مخصوص هر فاکتور در الگو یا متغیر قرار نگیرد. تأیید محدودیت متن/نشانی با ارائه‌دهنده لازم است.

## الگوی OTP — یک متغیر

```text
کد ورود به فاکتور دیجیتال کندو: {code}
```

فقط نام متغیر `code` است. کد و کلید API هرگز در مستندات، مخزن یا گزارش لاگ نشوند. فراخوانی فعلی در `src/Sms/FarazAdapter.php` endpoint HTTPS ثابت و هدر `Api-Key` را به‌کار می‌گیرد؛ دریافت پاسخ پذیرش ارائه‌دهنده به معنی تحویل نیست. شناسهٔ خطوط، الگوها و کلید از تنظیم خصوصی خوانده می‌شوند. در CI از ارسال واقعی جلوگیری می‌شود.

## بازبینی کمینه‌سازی داده — پیشنهاد، نه تصمیم حذف

`cloud_sms_announcements` اثبات اعلان تأییدشده و بودجه OTP؛ `cloud_sms_delivery_requests` مانع تکرار ارسال/ابهام؛ challenge و metadata idempotency برای replay و امنیت هستند. طبق حکم P-15 نباید اعلان تأییدشده، ردیف درخواست، fingerprint یا audit فعال را حذف کرد. پیشنهاد پیش از انتشار: مالک/حقوقی مدت نگهداری، تفکیک دادهٔ قابل حذف، دسترسی admin، نسخهٔ پشتیبان و نحوهٔ پاسخ به درخواست حذف را بررسی کند؛ کاهش داده فقط پس از تصویب و بدون نقض قرارداد و idempotency. لاگ دموی حاوی کد/شماره صرفاً محلی است و برای پشتیبانی خارجی ارسال نمی‌شود.

ثبت هزینهٔ هر SMS، schema، منبع قیمت و محاسبهٔ آمار هنوز اجرا نشده؛ رقم یا هزینهٔ ارسال واقعی حدس زده نمی‌شود. آزمون تحویل واقعی و ثبت الگو با ارائه‌دهنده **NOT-VERIFIED** است.

### برآورد هزینهٔ رزرو ارسال (محلی، اختیاری)

پیکربندی `sms_cost` به‌صورت پیش‌فرض خاموش است. با فعال‌سازی صریح، هر دو مقدار صحیح غیرمنفی `notification_rials` و `otp_rials` لازم‌اند (۰ تا ۹۹۹۹۹۹ ریال). ردیف برآورد به‌صورت تراکنشی هنگام رزرو هر تلاش اعلان یا OTP و بدون شماره یا متن SMS ثبت می‌شود؛ تکرار کلید، ردیف یا ارسال دوم تولید نمی‌کند. این **برآورد رزرو است نه هزینه واقعی، قبض، تحویل یا پذیرش ارائه‌دهنده**؛ تلاش نامطمئن یا توقف پس از رزرو هم ممکن است حساب شود و طول پیام/تعرفه واقعی با آن تفاوت داشته باشد. مالک باید برآورد را با صورت‌حساب تطبیق دهد؛ قیمت را حدس نزنید. CI از dry adapter و اطلاعات ساختگی استفاده می‌کند و هیچ SMS واقعی ارسال نمی‌کند.
